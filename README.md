# SQA Lab - Python Calculator

## Project Description

This is a simple Python calculator project created for the Software Construction and Development / Software Quality Assurance (SQA) lab.

The project demonstrates basic Python programming and is used to practice storing and managing source code using GitHub and analyzing code quality using SonarQube.

## Features

The calculator performs the following operations:

- Addition
- Subtraction
- Multiplication
- Division

## Project Structure

```text
SQA-Sample-Project/
│
├── calculator.py
└── README.md
```

## How to Run

1. Open the project in Visual Studio Code.
2. Make sure Python is installed.
3. Open `calculator.py`.
4. Run the program using the Run button or the following command:

```bash
python calculator.py
```

## Sample Output

```text
Addition: 15
Subtraction: 5
Multiplication: 50
Division: 2.0
```

## Tools Used

- Python

## Purpose

The purpose of this project is to learn basic software quality assurance practices, source-code management using GitHub, and code-quality analysis using SonarQube.
